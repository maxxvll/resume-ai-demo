围绕消息、文件与实时通信，打通客户端交互、服务端持久化和多端同步。

个人职责：完成产品设计、IM 核心链路、多端适配、自动化测试与多平台发布。

聊天与用户关系

支持好友申请与分组、单聊、群聊、群成员管理、回复、转发、撤回、收藏、已读状态和消息搜索。

富媒体消息

发送文字、图片、文件、语音和视频，并提供在线预览、转存、分享与下载。

文件云盘

管理目录、容量和对象引用，区分聊天文件与云盘文件的访问权限。

多端通信

会话内 AI

从本地数据中筛选有限上下文，通过 SSE 返回增量内容，完成后同步其他设备。

系统能力

通过 Tauri 使用文件系统、系统托盘、通知、剪贴板、扫码和窗口状态。

系统架构

客户端、实时通信、业务服务与存储协同，保证消息可达、状态可恢复、文件可追踪。

  1. 多端客户端

    Vue 3 与 Tauri 2，覆盖桌面端、移动端和浏览器调试。

  2. 接口与实时通信

    REST 处理业务请求，WebSocket 推送通知，SSE 输出 AI 回复。

  3. Java 业务服务

    管理账号关系、会话消息、文件分享和 AI 会话。

  4. 数据与事件

    MySQL 保存业务状态，Redis 加速热点访问，Kafka 传递事件，MinIO 存储文件。

音视频：服务端完成身份校验和信令转发，媒体尽量由终端通过 WebRTC 直接传输。

离线恢复：在线连接用于提醒，最终恢复依赖持久事件、设备游标和幂等合并。

关键工程设计

围绕消息可靠性、文件生命周期和 AI 回复同步解决三类核心问题。

消息只入库一次，断线后仍可恢复

客户端为一次发送保留稳定消息号，服务端先幂等落库再异步投递。在线设备通过 WebSocket 收到提醒，断线设备按持久事件和游标补拉，弱网重试不会重复入库。

文件可转存、可分享、可回收

MySQL 保存文件元数据、容量和引用关系，MinIO 保存对象内容。聊天文件与云盘文件采用不同访问入口，上传或转存失败时补偿清理，降低孤儿对象和错误鉴权风险。

AI 回复流式展示并同步多端

客户端从本地消息、收藏和联系人中筛选少量相关上下文，服务端校验会话并通过 SSE 返回增量内容，完成后持久化正式消息并同步其他设备。
